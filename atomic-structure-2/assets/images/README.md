# Image credit

`cricket_ball.png` is the same public-domain photograph used in Part 1. It was
created by Stephen Turner from Albinomonkey's *Cricketball 04.jpg* and centered
by David Levy. [Wikimedia Commons source](https://commons.wikimedia.org/wiki/File:Cricketball.png).
Source resolution: 325 × 325. Used proportionally in Scene 3; it is a photograph,
not a procedural ball mesh. All orbital meshes and density maps are calculated
by the project from the equations in `utils/physics_models.py`.

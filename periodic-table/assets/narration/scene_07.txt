Extend that column: lithium, sodium, potassium, rubidium and caesium. Their total electron counts are very different. Write just the outer configuration beside each atom, leaving its core aside. Two s one, three s one, four s one, five s one, six s one. The shared pattern is n s one. Here n labels the outer shell. The next column repeats n s two: beryllium, magnesium, calcium, strontium and barium. The halogens repeat n s two, n p five. Their outer s and p set is one electron short. Neon through xenon repeat n s two, n p six: closed outer s and p subshells. Let the element symbols fade for a moment. Keep only these recurring patterns. The s columns repeat s one and s two. The p columns progress from p one through p six. Different shell sizes, related outer electrons. This pattern is clearest in the main groups. A column gathers elements with recurring valence structure. The transition metals have more complicated patterns because d electrons also participate in their chemistry. And hydrogen is special: one s electron, but no closed inner core. Sharing a column does not make every member chemically identical. Bring the symbols back. The groups now organize a physical pattern, rather than just a set of names to memorize. The real test is chemical behaviour. What does that repeated outer pattern let an atom do?

[warm, conversational delivery] When we throw a ball, we usually treat it as a point. A point has mass, but no size. To trace the ball's path through the air, that is often all we need. [short pause] [curious] But try that with a spinning wheel. A point near the axle sweeps a tiny circle. A point on the rim travels much farther, in the same time. One dot can't describe both. So we treat the wheel as an extended body: many particles, at many different positions. [short pause] And we make one simplifying assumption. The distance between any two particles never changes. The body doesn't stretch, bend or squash. We call it a rigid body. Real materials do deform a little. But when that deformation is tiny, the rigid model works remarkably well. A rigid body can move in three ways. In pure translation, every particle has the same velocity. The body shifts, but never turns. In fixed-axis rotation, points away from the axis move on circles. Points on the axis stay still. Farther out means faster. [short pause] [emphasized] And in rolling, it does both at once. So to describe an extended body, knowing where it is isn't enough. We also need to know how it is turned, and how that is changing. [pause] [warmly] Let's start with the first part. Where is it?

## Description

Machine learning almost never gives you absolute truth - it gives you probability. In this
chapter, we build up probability from first principles, using the examples every ML learner
runs into: spam filters, image classifiers, medical diagnosis, and fraud detection.

We cover:
- Probability as a function: P(A)
- Complement, addition, and multiplication rules
- Conditional probability and Bayes' theorem
- Random variables, probability distributions, and expected value
- Joint and marginal probability
- Independence and why ML features usually are not independent
- Why supervised ML often estimates P(y|x)

This is Chapter 4 of the Statistics for ML series. Previous chapters covered descriptive
statistics, spread, and correlation - this chapter turns to the language that lets models
reason under uncertainty.

Referenced texts: Introduction to Probability (Blitzstein & Hwang), Think Bayes (Downey),
All of Statistics (Wasserman), Pattern Recognition and Machine Learning (Bishop),
Probabilistic Machine Learning (Murphy), An Introduction to Statistical Learning (James et al.).

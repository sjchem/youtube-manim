## Title

Mean, Median, Variance & Standard Deviation for ML | Statistics for ML - Part 1, Chapter 3

## Description

Before a machine learning model learns from data, we need to understand the data ourselves.

This chapter explains descriptive statistics for ML through animated visuals: mean, median, mode, variance, standard deviation, percentiles, covariance, and correlation. We use these ideas to inspect outliers, compare feature scales, understand distributions, and check relationships before modeling.

Topics covered:
- Mean, median, and mode
- Outliers and robust center
- Variance and standard deviation
- Worked variance example
- Percentiles and rank
- Histograms, skew, and IQR
- Feature scaling with z-scores
- Covariance and correlation
- Worked correlation example
- A practical pre-model checklist

References used for the explanation:
- OpenStax Introductory Statistics
- Khan Academy Statistics and Probability
- An Introduction to Statistical Learning
- Think Stats by Allen B. Downey
- Scikit-learn documentation on preprocessing

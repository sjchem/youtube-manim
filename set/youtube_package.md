# YouTube package — draft

## Title

**What Pizza Can Teach You About Set Theory**

Alternative: **Set Theory Explained with Pizza, Animals, and Pictures**

## Description

One friend wants no meat. Another wants no dairy. Can one pizza make them
both happy? Start with this familiar choice, then explore sets, membership,
subsets, the empty set, union, intersection, complement, and De Morgan’s laws.

Fruit baskets, animal habitats, a platypus, number counters, and a topping
conveyor make each idea visible before the symbols arrive. Each example then earns a
large mathematical rule, with Scene 12 joining the rules into one chain. Real 3D pizza,
lunchboxes, a kitchen shelf, and matching stencils add changes of perspective.

Made with Manim Community Edition and the local Oceanic Next theme.

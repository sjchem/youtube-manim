# ElevenLabs narration

Paste each of the 14 files in `scripts/` into ElevenLabs with your own cloned
voice. The passages explain each mathematical statement after the visual
example. Planned runtime is 21:56; the script contains 2,644 spoken words.

`narration_pacing.csv` estimates speech at 135 words per minute and is not a
measurement of generated audio. Listen to the recorded clips and align the
scene cues before producing the final narrated video. Current review videos
are silent. Regenerate the text files with `python -m utils.export_narration`.

Before we return to the pizza, let us pack something simpler: a fruit basket. Here are an apple, a banana, a pizza slice, a strawberry, a carrot, and some grapes. We need a clear rule for what goes into the basket. Choose the fruit, and four objects move inside. The pizza and carrot stay outside. The collection we have selected is a set. Its membership is well defined: each object either belongs or does not. Let us call this fruit set A. Curly braces let us list its members. The list tells us what is in the collection without needing to draw a basket every time. Look at the apple. It belongs to A, so we write apple, followed by the membership symbol, followed by A. That symbol means “is an element of.” The pizza does not belong. A line through the symbol changes the statement to “is not an element of.” These are simply two ways of answering the same question. Now keep the apple, banana, and grapes, and shuffle them around. Did their positions change? Yes. Did the members change? No. The set is still the same. Repetition is similar. These three apple pictures repeat the same named element, apple. They do not represent three individually identified physical apples. Writing that name several times adds no new member. Apple and banana still give us two distinct elements. A set keeps track of membership, rather than order or repetition. Now write the basket as a set of named elements: A equals apple, banana, strawberry, and grapes in braces. For any object x in our collection, x belongs to A exactly when it passes the fruit rule.
